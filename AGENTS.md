# Project-local design skills

The frontend design skills for this repository are in `.agents/skills/`:

- `impeccable` — design quality bar and craft-floor rules.
- `emil-design-eng` — design-engineering guidance, including motion and interaction details.
- `design-taste-frontend` — general frontend layout and visual judgment.

When the user names one of these skills, or a frontend design task would benefit from it, read its `SKILL.md` and follow its guidance for that task.
